# agent-env-kit

AI開発ワークフローを改善するためのプラグインを開発・管理するリポジトリです。他の開発リポジトリで、必要な拡張を選んで利用できる形を目指します。

機能別の拡張と、同じ目的に対する別案の比較実験を扱います。最初の製品として、導入先の状況を調べ、ユーザーと相談しながら開発環境を整えるセットアップ・メンテナンス拡張を設計しています。

## 現在の状態

構想・設計段階です。現在は要求とリポジトリ運用の文書があり、利用可能なプラグイン本体や導入手順はまだありません。提供形式、対応環境、配布方式、実装言語は未決定です。

## プラグイン一覧

| プラグイン | 目的 | 状態 | 要求・仕様 |
| --- | --- | --- | --- |
| セットアップ・メンテナンス拡張（仮称） | 導入先に適した指示、検証環境、開発手順などの整備・見直し | 構想・設計段階 | [開発依頼書](PROJECT_BRIEF.md) |

新しい拡張や継続比較する別案を追加したら、この一覧に用途、状態、参照先を記載します。

## 文書の入口

- 利用を検討する方：[開発依頼書](PROJECT_BRIEF.md)で最初の拡張の対象と要求を確認できます。実装後は各プラグインのREADMEへ導入・利用方法を記載します。
- 開発する方：[構成・運用方針](docs/repository.md)で配置、文書の正本、実験・検証の進め方を確認してください。
- 作業するエージェント：[AGENTS.md](AGENTS.md)に、このリポジトリでの判断規則と検証の入口があります。

Pythonファイルの編集後は、[Pythonの整形・lint手順](docs/repository.md#pythonの整形lint)に従ってRuffを実行します。
